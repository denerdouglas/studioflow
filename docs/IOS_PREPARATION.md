# Preparação para iOS

O diretório iOS existe, porém esta Sprint não compila no Windows. Para publicação serão necessários macOS/Xcode atualizados, Bundle ID definitivo, Apple Developer Team, certificados/perfis, ícones AppIcon, splash, textos de privacidade da câmera, versão 1.0.0 (build 6), archive e validação no TestFlight.

Também devem ser testados SQLite/migração, câmera, links externos, acessibilidade, modo offline e atualização preservando dados. Nenhuma chave Apple foi criada ou alterada.
