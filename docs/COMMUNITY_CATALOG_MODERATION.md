# Moderação do Catálogo Comunitário

Parceiros enviam somente dados gerais mediante consentimento explícito. A sugestão começa como `pendente`; nunca altera diretamente `catalogo_produtos`.

Estados previstos: `pending`, `accepted`, `rejected`, `needsMoreEvidence`, `merged`, `canceled`. Níveis de confiança: `official`, `verified`, `trustedCommunity`, `communitySubmitted`, `pending`, `disputed`, `blocked`, `archived`.

Cada alteração mantém sugestão, usuário, comércio, GTIN, JSON de comparação, motivo, fonte, datas e moderador. A moderação global pertence a um painel administrativo futuro; donos de salão não recebem esse privilégio. Imagens particulares não substituem imagens globais sem revisão de licença e conteúdo.
